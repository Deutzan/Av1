[10,0 pts] Questão 2) CSS 
Considerando o arquivo index.html construído na Questão 1 (e vinculado-o a uma folha de 
estilos externa chamada index.css) crie o conteúdo do arquivo index.css de modo que a página 
resultante fique visualmente igual à tela de referência (protótipo) apresentada. 
Seu arquivo CSS deve contemplar, no mínimo: 
I) Definição de fonte e cor de fundo para o <body>; 
II) Centralização e largura fixa para a <table>, com espaçamento entre bordas (border-collapse); 
III) Bordas e espaçamento interno (padding) para as células (<td>); 
IV) Cor de fundo diferenciada para o cabeçalho e para o rodapé; 
V) Estilização da imagem de perfil (ex.: borda arredondada); 
VI) Cor do link e um efeito ao passar o mouse (:hover).
